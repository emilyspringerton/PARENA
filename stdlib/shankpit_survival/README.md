# SHANKPIT SURVIVAL (PARENA)

The SHANKPHONE's **Survival** button (founder, 2026-11-26: *"the shankphone itself can have a button for survival that launches OG
shankpit as a level and collection of mods"*; asked for as a PARENA rewrite, not a port of the C client's OpenGL). The OG C client's
SURVIVAL mode (`SHANKPIT/apps/lobby`, `lobby_start_survival_mode` + `witness_ai_survival_tick`), rebuilt as:

- **the engine**: shankpit-460's PARENA engine, unchanged in behaviour (`stdlib/shankpit460/`: the software renderer, physics,
  input, HUD). It now has a **mod surface** (`stdlib/shankpit460/sp_mods.prn`, 14 hooks). The arena build links the no-op hooks.
- **a level**: `sv_city.prn`, SHANKPIT's CITY, generated by the C client's `init_city_geo` formulas on the same seed (districts,
  heights, footprints, ramps, ruins, landmark towers), 7 x 7 blocks around the spawn plaza (the C city is 25 x 25), with a low wall at
  the edge.
- **mods**: `sv_mod.prn`: waves, zombies, the arsenal (knife only; guns on the roads and from 35% of kills), loot chests,
  death ends the run.
- **rules**: what the mode IS lives in PARENA rule files the C client can share: `stdlib/shankpit/survival_rules.prn` (new: wave quota
  4 + 3n, at most 5 + n alive, one zombie every 15 s, a 6 s rest, the hidden 60..130 ring, zombie 100 hp / 14 damage / 3 units /
  1.1 s, the gun loot table) and the existing `stdlib/shankpit/chest_rules.prn`.

One wasm32 module, the same build guarantees as the arena: no allocator, no imports, fixed 8 MB, 232 KB.

```bash
scripts/build_shankpit_survival_wasm.sh /tmp/survival.wasm
node tests/shankpit_survival_test.mjs /tmp/survival.wasm     # 31 checks, plays the mode headlessly
scripts/test_shankpit460.sh                                    # the arena's parity / engine / soak legs + this one
```

It ships inside the SHANKPHONE (`SHANKPIT/android-netkit`, page `SHANKPIT/apps/netkit`, host
`stdlib/netkit/host/nk_host_survival.prn`).

## Honest limits

- Deviations from the C client: the 7 x 7 city instead of 25 x 25; no ring highway, hydrants or props; one zombie class (the base
  walker) with a plain chase brain (the bots' steering) instead of witness_ai's moods, hunger and infighting; 9 zombie slots, not 16
  (a capped wave waits, it is never skipped); the missile launcher (weapon 6) comes out of chests as the sniper; no flashlight; katana
  slashes do not hit chests (knife and guns do); no day/night.
- No sound in the SHANKPHONE yet. The engine fills its sound ring, but nothing plays it.
- Not played by a person on a device yet. The headless test and headless Chromium drive it.
